# PhantomDaze

个人博客，记录 Linux、开发工具和一些折腾过程。

- 站点：https://antomie.pages.dev
- 框架：[Astro](https://astro.build)
- 主题：[Mizuki](https://gitee.com/matsuzakayuki/Mizuki)

## 本地运行

```sh
pnpm install
pnpm dev
```

构建与预览：

```sh
pnpm build
pnpm preview
```

## 内容

文章位于 `src/content/posts/`，关于与友链页面位于 `src/content/spec/`，站点配置位于 `src/config.ts`。
